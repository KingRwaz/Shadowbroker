# Rachael Nanyonjo × AFCON PAMOJA 2027 — Design System

## Core concept
**UGANDA: THE CULTURE BEHIND THE GAME**

The visual and presentation system positions Rachael Nanyonjo as an international creative practitioner who can help translate Ugandan culture into high-quality visitor, cultural and live-event experiences around AFCON 2027.

## Assets
- `rachael-afcon-cultural-experience-concept.svg` — 1600×900 original concept visual.
- `rachael-afcon-visual-direction.md` — visual direction and presentation rules.
- `rachael-afcon-2027-pitch-deck.html` — 10-slide browser presentation.

## Visual language
- Midnight/navy foundation
- Warm gold as cultural pulse / premium accent
- Restrained red for energy and emphasis
- Contemporary editorial typography
- Abstract movement/orbit/landscape motifs
- Rachael's own licensed portfolio photography should replace abstract figure elements in a final stakeholder deck

## Usage rules
1. This is an independent creative proposition, not an official AFCON/CAF identity.
2. Do not recreate or imitate official CAF/AFCON marks without permission.
3. Use only licensed or Rachael-owned photography.
4. Keep Rachael's personal/professional identity visually independent from tournament branding.
5. Tailor the partnership slide and call-to-action to each stakeholder.
6. Re-verify operational facts before external circulation.

## Recommended stakeholder variants
- AFCON Uganda LOC — fan experience / cultural programming / event operations
- Uganda Tourism Board — destination / hospitality / diaspora tourism
- Cultural institutions — artists / venues / legacy / capacity development
- Hospitality partners — guest experience / cultural nights / destination storytelling
- Experiential agencies and sponsors — creative direction / branded activations
